# EastBus – Smart Transportation Management System

EastBus is an AI-based smart transportation management platform developed for private long-distance bus services in Sri Lanka’s Eastern Province.

The system provides dedicated applications and web portals for passengers, bus staff, bus operators, and system administrators to manage transportation services through a centralized digital platform.

## EastBus Applications

### 1. Passenger Mobile Application

The **EastBus Passenger App** is developed using Flutter and provides passengers with convenient access to bus services.

#### Key Features

- Passenger Registration & Login
- Bus Search
- Route & Trip Information
- Bus Details
- Seat Selection
- Digital Seat Booking
- E-Ticket Generation
- QR-Based E-Ticket
- Booking History
- Real-Time Bus Tracking
- Estimated Arrival Information
- AI-Based Bus Recommendations
- AI Chatbot Assistance
- Passenger Profile Management

---

### 2. Trip Management Mobile Application

The **EastBus Trip Management App** is developed using Flutter for bus staff to manage assigned trips and operational activities.

#### Key Features

- Bus Staff Login
- View Assigned Trips
- View Trip & Route Details
- Start Assigned Trips
- Scheduled Departure Validation
- Real-Time GPS Location Sharing
- Passenger Booking Information
- QR Ticket Scanning
- Passenger Check-In
- Trip Status Management
- End Trip
- Real-Time Location Updates to the EastBus Platform

The application communicates with the EastBus backend to provide real-time operational information to passengers and system administrators.

## Technology Stack

- **Mobile Applications:** Flutter / Dart
- **Backend:** Laravel REST API

- **Maps:** OpenStreetMap
- **AI Integration:** Gemini AI
- **Notifications:** Firebase Cloud Messaging (FCM)

---

## Project Purpose

EastBus aims to modernize private long-distance bus transportation in Sri Lanka’s Eastern Province.

The platform addresses challenges such as the lack of centralized bus information, manual seat booking, limited real-time bus tracking, inaccurate arrival information, and limited digital communication between passengers and bus service providers.
