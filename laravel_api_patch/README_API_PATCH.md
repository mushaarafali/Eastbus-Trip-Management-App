# Laravel REST API Patch for EastBus Trip Management App

This patch is intended for the previously generated `eastbus_admin_operator` Laravel project.

It adds:

- Staff token authentication
- Driver/Conductor login by login ID, phone, or email
- Staff profile endpoint
- Assigned-trip dashboard and trip list
- Start/End Trip
- Live GPS location receiving
- Passenger manifest
- QR ticket verification and anti-reuse check-in
- Notifications
- Emergency alerts
- `booking_passengers`, `tickets`, and `staff_api_tokens` tables

See the root `README.md` for installation steps.
